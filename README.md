# Cherry Chance Game Lab

**Responsible chance-game research** — UX analysis, mechanics, probability education, and entertainment-budget tools.

## 1. What this project does
Produces responsible reviews and tools: theme/visual design, bonus-mechanic taxonomy, volatility explainers, session journaling, entertainment-budget trackers, accessibility notes, and game QA checklists.

## 2. Who it is for
Cherry, gaming content / QA / UX research roles, and portfolio reviewers.

## 3. What exists today
Foundation structure.

## 4. What is planned
One slot-game UX and mechanics review (clarity, volatility, entertainment value, accessibility, responsible-play observations) as the first proof.

## 5. What it does not claim
No guaranteed-win claims, predictive systems, loss-chasing mechanics, or undisclosed affiliate promotion. Random outcomes are not controllable. Actual spending data stays private.

## 6. First proof artifact
One slot-game UX and mechanics review with responsible-play observations.
